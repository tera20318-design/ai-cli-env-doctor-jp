# Changelog

All notable changes to this project will be documented in this file.

These notes describe the initial public repository state for v0.1.0.

## [0.1.0] - 2026-06-01

### Added

- Initial Python CLI package.
- Japanese text report output.
- JSON report output with a stable top-level schema.
- Read-only checks for Python, Git, Node.js / npm, uv, Codex CLI, PowerShell, and PATH.
- `--check` for selecting individual checks.
- `--strict` for CI-oriented non-zero exit codes.
- Unit tests that mock command discovery and subprocess calls.
- GitHub Actions CI configuration.
