# Roadmap

This roadmap lists possible future work. It is not a promise that the features already exist.

## v0.1.x

- Improve wording for common Windows PowerShell and npm shim failures.
- Add more tests for malformed version output and timeout handling.
- Add examples for GitHub Actions usage with `--strict`.

## Later Candidates

- Optional verbose mode that shows carefully redacted command paths.
- Shell-specific notes for Bash, zsh, fish, PowerShell, and Git Bash.
- Rule packs for common AI development stacks.
- Optional export to Markdown for support requests.

## Out Of Scope For Now

- Automatic installation or repair.
- Network-based version checks.
- Telemetry.
- Claims about adoption, downloads, or usage metrics.
